방향 결정 — 디자인 시안 3개

스크린샷에서 드러난 문제 진단 + 새 시각 방향 후보

먼저, 솔직히 말하면… 스크린샷이 못생긴 건 디자인 콘셉트 문제보다는 CSS 누수 + 두 스타일 시스템이 갈라진 결과야:
  • 격자선이 보이는 이유 — HeroDemo는 Docusaurus Infima의 table th, td { border: 1px solid }를 리셋 안 함. .kx-live-*는 이슈 #35로 이미 해결했는데 hero에는 적용 누락.
  • MonthPicker 가로로 늘어진 이유 — .kx-live-month-grid의 display:grid; columns:3 규칙이 hero엔 없음. <table> 그대로 떨어져서 컬럼 12개가 한 줄로 나옴.
  • DateTimePicker 답답한 이유 — 인라인 style={{ display:'flex', gap:8 }}만 있고 컬럼 너비 힌트 없음.
→ 즉, "근본 재설계"가 아니라 「하나의 시각 시스템으로 통일 + 진짜 폴리시 한 번」이면 거의 다 잡혀. 그 위에서 방향을 골라보자.
