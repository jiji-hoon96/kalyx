# Track 1 PR-A2 — Landing Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the 375-line monolithic landing (`apps/docs-site/src/pages/index.tsx`) with a six-section composer that mounts `<Hero>` (with a lazy `<HeroDemo>`), `<FeatureGrid>`, `<SameJsxBlock>`, `<PickerGrid>`, `<WhyKalyx>`, `<GetStarted>`. Ship Korean translations and a fresh `og-hero.png` extracted from PR-A1's recorder pipeline.

**Architecture:** Each section lives in its own folder under `apps/docs-site/src/components/`. Static content (4 features, 7 pickers) lives in `data.ts` next to the component. The hero's right column wraps `<HeroDemo>` in `React.lazy` + `<Suspense>` + `<BrowserOnly>` so the SSG bundle only contains a static `<img>`. The Vite/vitest test runner aliases `@docusaurus/*` to no-op mocks so each component can be smoke-tested in isolation.

**Tech Stack:** React 19, Docusaurus 3.10, Vitest + Testing Library + jest-axe (already wired in workspace), Playwright (already installed, used only by the existing recorder).

**Scope:** Six new component dirs + a new `index.tsx` + a `--still` flag on `scripts/record-hero.mjs` + a third file watched by `scripts/check-hero-freshness.mjs` + Korean translations in `apps/docs-site/i18n/ko/code.json`. No changes to `packages/react`. No new CI workflow jobs.

**Reference spec:** `docs/superpowers/specs/2026-06-10-track1-pr-a2-landing-redesign-design.md`

```javascript
async function main() {
  ensureCwebp();

  const tmpDir = resolve(REPO_ROOT, '.tmp-hero-frames');
  await rm(tmpDir, { recursive: true, force: true });
  await mkdir(tmpDir, { recursive: true });

  const server = startDocsSite();
  try {
    await waitForPort(DOCS_PORT, SERVER_TIMEOUT_MS);

    if (args.still) {
      const stillAbs = resolve(REPO_ROOT, args.still);
      await captureStill(stillAbs);
      console.log(`[record-hero] wrote ${args.still} (still, frame 0)`);
      const stat = statSync(stillAbs);
      console.log(`[record-hero] size: ${(stat.size / 1024).toFixed(1)} KB`);
      return;
    }

    await captureFrames(tmpDir);
    await encodeWebp(tmpDir, outAbs);
    console.log(`[record-hero] wrote ${out}`);
    const stat = statSync(outAbs);
    console.log(`[record-hero] size: ${(stat.size / 1024).toFixed(1)} KB`);
  } finally {
    server.kill('SIGTERM');
    await rm(tmpDir, { recursive: true, force: true });
  }
}
```

- [ ] **Step 3: Add the `captureStill` helper**

Append below `encodeWebp`:

```javascript
async function captureStill(outAbs) {
  await mkdir(dirname(outAbs), { recursive: true });
  const browser = await chromium.launch();
  try {
    const ctx = await browser.newContext({
      viewport: VIEWPORT,
      colorScheme: theme,
    });
    const page = await ctx.newPage();
    const url = `http://localhost:${DOCS_PORT}/recorder?frame=0&theme=${theme}`;
    await page.goto(url, { waitUntil: 'networkidle' });
    await page.waitForTimeout(250);
    await page.screenshot({ path: outAbs, type: 'png' });
  } finally {
    await browser.close();
  }
}
```

```tsx
import { lazy, Suspense } from 'react';
import BrowserOnly from '@docusaurus/BrowserOnly';
import StaticHero from './StaticHero';

const HeroDemo = lazy(() => import('../HeroDemo'));

/**
 * The right column of the hero. Wraps <HeroDemo> in BrowserOnly +
 * Suspense so:
 *   - the SSG pass emits only <StaticHero /> (no React.lazy on the server)
 *   - the lazy chunk replaces the placeholder once it loads on the client
 *
 * Marked with data-testid so smoke tests can assert the slot exists
 * without resolving the real HeroDemo (which would pull in @kalyx/react).
 */
export default function HeroDemoSlot() {
  return (
    <div data-testid="hero-demo-slot">
      <BrowserOnly fallback={<StaticHero />}>
        {() => (
          <Suspense fallback={<StaticHero />}>
            <HeroDemo />
          </Suspense>
        )}
      </BrowserOnly>
    </div>
  );
}
```

It DOES fail if a `<Translate>` is missing child default text.
